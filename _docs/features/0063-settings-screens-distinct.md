# 0063: 会話の設定・設定・管理の画面を見分けやすくする(効く範囲の帯・一覧を畳む・管理の色)

- 前提: 0009(会話の設定)、0014(プロファイル)、0032(管理の画面)、0053(確定式の画面と `SaveBar`)、0018(プロファイルを配る)

## 目的

会話の設定・設定・管理の3つの画面が同じように見え、「今どこを触っているのか」「これで合っていたか」が分かりにくい(2026-11-24、ユーザーの指摘。UI というより UX の問題)。
見た目と言葉で、**その画面で変えたものがどこに効くか**が一目で分かるようにする。

学ぶこと:

- **効く範囲を見せる**:同じ入力欄でも、効く範囲(この会話だけ・これから作る会話・ほかの人の会話)が違えば、間違えたときの被害が違う。範囲を画面に書いて、使う人が確かめられるようにする
- **周りの見た目で場所を伝える**:見出しの文字を読まなくても、一覧の出方と色で「会話の中」か「会話の外」かが分かるようにする

## 今の作り(2026-11-24、Chat がコードを読んで確かめた)

- 3つの画面は同じ部品でできている(`section.settings-view` > `.settings-inner` > `.settings-header`(`h1` と「← 会話に戻る」)、タブは `.settings-tabs`)。違うのは `h1` の文字(「会話の設定」「設定」「管理」)だけ
- どの画面を開いても、左の会話の一覧は開いたまま。設定・管理を開いていても、開いていた会話の行が選ばれた色(`.conversation.current`。`ConversationList` の `selectedId`)のままで、その会話の設定を触っているように見える
- **同じ入力欄(`ConversationSettingsForm`・`LimitsForm`)が3か所に出る**が、効く範囲が違う
  - 会話の設定(入力欄の下・メーターの右の歯車):この会話だけ
  - 設定 > 会話(プロファイル。`ProfileSettings`):これから作る自分の会話の既定(今ある会話には効かない。決まりはそのプロファイルから作った会話にすぐ効く)
  - 管理 > 配布プロファイル(`ProfileSettings mode="distributed"`):配った相手全員の会話
- 入口:会話の設定は入力欄の下の歯車、設定は一覧の左下の歯車、管理は左下の盾(`LuShield`)。歯車が2つある
- 一覧には、すでに「畳んだ細い列」(`ConversationList` の `open=false`。メニュー・+・管理の盾・設定の歯車だけ)がある。開け閉めは `App.tsx` の `listOpen` で、自分で開け閉めしたときだけ `STORED_LIST_OPEN` に覚える

## 決定事項(ユーザーと決めたこと。2026-11-24)

1. **効く範囲の帯(A)**:3つの画面の見出しのすぐ下に、その画面(タブ)で変えたものがどこに効くかを1行で出す
2. **一覧の扱い(B)**:**設定と管理の画面を開いている間は、会話の一覧を畳んだ細い列にし、会話の選択の色も外す**。隠しはしない(一覧の細い列から歯車・盾・+ で移れるように)。
   会話の設定の画面では、一覧は今のまま出し、その会話を選んだ色のままにする
3. **管理だけ色を変える(C)**:管理の画面だけ、見出しに盾のアイコンと、注意の色の細い帯を付ける(ほかの人に効く画面であることを色で分ける)。設定と会話の設定の画面は今の色のまま
4. **会話の設定を右から出るパネルにする案(D)は採用しない**。モーダル(真ん中のダイアログ)にもしない

## 決定事項(話の流れから Chat が決めて書いたこと。2026-11-24)

着手の前に、ユーザーにこのとおりでよいかを確かめる。

### A. 効く範囲の帯

5. 帯は見出し(`.settings-header`)とエラー(`ScreenErrors`)の間、タブがある画面ではタブの下(タブごとに効く範囲が違うため)に出す。部品は1つ(例:`ScopeNote`)にし、3つの画面で使う
6. 見た目は控えめな1行(薄い背景か左の線・小さめの文字・情報のアイコン)。管理の画面では C の色に合わせる。マウスを乗せた説明(title)は今のまま残す
7. 文言の案(0048 の決まりに沿う。造語を使わない。最終的な言葉は Code が画面で見せてユーザーが確かめる):

   | 画面・タブ | 帯の文 |
   |---|---|
   | 会話の設定 | この会話「(会話の名前)」だけに効きます。ほかの会話とプロファイルは変わりません |
   | 設定 > 基本設定 | この画面の見た目に効きます(ブラウザでは、このブラウザ。アプリでは、この PC) |
   | 設定 > モデル(アプリモード) | この PC のモデルに効きます。読み込み・アンロードはすぐ効きます |
   | 設定 > モデル(一覧だけ) | 使えるモデルの一覧です。ここでは変えられません |
   | 設定 > 会話(プロファイル) | これから作る自分の会話の既定です。今ある会話の設定は変わりません(固定・使えないの決まりは、そのプロファイルから作った会話にすぐ効きます) |
   | 設定 > ワークスペース・MCP | この PC の、全部の会話に効きます |
   | 設定 > サーバー | このアプリのつなぎ先です。起動し直すと切り替わります |
   | 設定 > グループ | 自分が長のグループのメンバーに効きます |
   | 設定 > アカウント | 自分のアカウントに効きます |
   | 管理 > 利用者・グループ | aibow-server の利用者に効きます |
   | 管理 > モデル | aibow-server を使う全員に効きます |
   | 管理 > ツール | ブラウザから使う全員の会話の既定に効きます |
   | 管理 > 配布プロファイル | 配布した相手の会話にすぐ効きます |
   | 管理 > 資料のフォルダ | 配布プロファイルで選ぶフォルダです。変えるとすぐ効きます |
   | 管理 > 使用量 | 見るだけです |
   | 管理 > ログ | aibow-server のログに効きます。起動し直すと元に戻ります |

8. **保存のバーにも短く添える**:確定式の画面(0053 の `SaveBar`)で、効く範囲がほかの人に及ぶところ(管理 > 配布プロファイル・管理 > ツール・管理 > モデルの並列数と作業領域)は、「保存」の左に「全員に効きます」のような短い文を出す。
   `SaveBar` に任意の `scope`(文字)を足す形を想定している(形は Code が決めてよい)。自分にだけ効くところ(会話の設定・自分のプロファイル)には出さない

### B. 一覧を畳む

9. 設定・管理の画面を開いたら、一覧を畳んだ細い列で出す。**覚えている開け閉め(`STORED_LIST_OPEN`)は変えない**。閉じて会話に戻ったら、開く前の開け閉めに戻る
   (`App.tsx` で `listOpen` そのものは変えず、`ConversationList` に渡す `open` を「設定・管理を開いていない かつ listOpen」にする形を想定している)
10. 設定・管理を開いている間に、細い列のメニュー(一覧を開くボタン)を押したら、そのときだけ一覧を開いてよい(会話を選べば、今どおり画面を閉じて会話に戻る)。そのときも会話の選択の色は付けない
11. 設定・管理を開いている間は、一覧の `selectedId` の色(`current`)を付けない(会話の設定の画面は付けたまま)
12. 狭いとき(`narrow`)は今も細い列なので、そのまま(重ねて出す一覧も、開いたときの動きは今のまま)
13. 0049 の決定事項 1(設定・管理から「+ 新規」で戻ったとき、ワークスペースを外さない)は変えない

### C. 管理の色

14. 管理の画面の `h1` の前に盾のアイコン(入口と同じ `LuShield`)を付け、画面の上の端(`.settings-view` か `.settings-header`)に注意の色(`--warn`)の細い帯(3px ほど)を付ける。ライト / ダークの両方で確かめる
15. 一覧の細い列の盾のボタンは、管理の画面を開いている間 `active` に加えて注意の色にする(今どこにいるかを入口でも見せる)
16. 設定・会話の設定の画面には色を付けない(全部に色を付けると、色の意味が薄れるため)
