# 0062: ワークスペースごとの一覧で、会話の無いワークスペースを出すかを切り替える

- 状態: ⬜ 未着手
- ロードマップ: ロードマップの外(画面の改善。0038 の続き)
- 決めた日: 2026-11-24(Chat でユーザーと決めた。Chat がコード(`_cmd/aibow/frontend/src/conversationGroups.ts`・`components/ConversationList.tsx`・`stored.ts`)と `_docs/ui.md` を読んで、今の作りを確かめた)
- 前提: 0035(ワークスペース)、0038(会話の一覧の並べ方。決定事項 4 で「会話の無いワークスペースも、「+」で始められるよう名前の順で後ろに出す」と決めていた)、0055(検索・非アクティブ)

## 目的

会話の一覧を「ワークスペースごと」にしたとき、会話の無いワークスペースも見出しとして出ている(0038 の決定事項 4)。
ワークスペースが増えると、会話の無い見出しだけで一覧が埋まってしまう。既定では出さず、出したいときだけ出せるようにする。

学ぶこと:

- **既定を「少なく見せる」側に倒す**:全部出すと入口は増えるが、見たいものが埋もれる。めったに使わないものは切り替えの後ろに置く

## 決定事項(ユーザーと決めたこと)

1. **会話の無いワークスペースを出すかを切り替えられるようにし、既定は出さない**(2026-11-24。Chat で「隠す / 1つにまとめて畳む / 切り替え」の3案から、ユーザーが切り替えを選んだ)。
   0038 の決定事項 4 の「会話の無いワークスペースも名前の順で後ろに出す」は、切り替えを入れたときだけの動きになる

## 決定事項(Chat が案を書き、ユーザーが確かめたこと。2026-11-24)

2. **切り替えは、一覧の上の並べ方のメニュー(`GroupingMenu`)の中に置く**。並べ方の2行の下に区切りを入れ、チェックの付く1行「会話の無いワークスペースも出す」(`role="menuitemcheckbox"`)。
   並べ方が「ワークスペースごと」のときだけ出す(新しい順では意味が無いので)。押したときにメニューを閉じるかは Code が触って決めてよい
3. **切り替えは PC ごとに localStorage に覚える**(例:`aibow.listShowEmptyWorkspaces`。既定(出さない)は覚えない)。並べ方・畳んだまとまりと同じ「見た目の好み」で、
   ワークスペースが PC のものなので(0038 の決定事項 3 と同じ理由)。狭いときは一覧の部品が2つ描かれるので、`conversationGroups.ts` のほかの値と同じく部品の外に1つだけ持つ(`useSyncExternalStore`)
4. **「会話の無い」の数え方は今と同じ**:一覧に出るアクティブの会話が無いワークスペース。会話が全部非アクティブのワークスペースも「会話の無い」側に入る
   (非アクティブの会話は下の「非アクティブ」の折りたたみに出る。0055)
5. **検索しているあいだは、切り替えによらず会話の無いワークスペースを出さない**(今は検索中も出ていて、当たった会話が埋もれる)
6. **開いている会話のワークスペースを入力欄の上で変えた直後**は、今と同じく一覧を読み直す前にすぐ移す(0038 の決定事項 10)。移った先は会話が1つあるので、切り替えによらず出る
7. 出さないときに会話の無いワークスペースで始めるには、上の「+ 新規」→ 入力欄の上のワークスペースで選ぶ(0035 の今の動き)。新しい入口は作らない

## やらないこと(先回りしない)

- 会話の無いワークスペースを1つの見出しにまとめて畳む形(Chat で出した別案。ユーザーは選ばなかった)
- ワークスペースごとに「一覧に出す / 出さない」を決める
- 並べ方「新しい順」・ブラウザ(aibow-server。メニュー自体が無い)の動きを変えること
