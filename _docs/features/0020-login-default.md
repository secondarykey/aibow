# 0020: aibow-server の既定をログイン必須にする

- 状態: ✅ 完了(2026-10-26。段 1・2。確かめたことは下の「確かめたこと」)
- ロードマップ: ロードマップの外(ステップ11のあと。0017 の決定事項 8「127.0.0.1 だけなら既定はログインなし」を決め直す)
- 決めた日: 2026-10-26(Code でユーザーと決めた)
- 前提: 0017(利用者・ログイン・API キー)、0018(管理者。最初の管理者はコマンドで決める)、0019(アプリのログイン)

## 目的

**aibow-server を、何も書かなければログインが要る形で起動する**。
きっかけ:管理者を作ってブラウザで開いたら、ログインなしで入れた(既定がログインなしで、`-login` を付けていなかったため。2026-10-26)。
ステップ10の既定は「1人で自分の PC だけで使う」ことを前提にしていたが、ステップ11で管理者と共有ができ、利用者を作ること自体が「ログインして使う」つもりの表れになった。
既定を守る側に倒し、ログインなしは決めた人だけが選ぶ形にする。

## 決定事項(ユーザーと決めたこと。2026-10-26)

1. **既定はログイン必須。外す道も残す**:`-login=false`・`server.json` の `"login": false`・`AIBOW_SERVER_LOGIN=0` を書いたときだけ、127.0.0.1 でログインなしにできる(1人で自分の PC だけで使うとき)。
   127.0.0.1 の外で待ち受けるときは、今までどおり書いた値によらずログインが要る(0017 の決定事項 2)
2. **パスワードのある管理者がまだいないとき(初めての起動など)は、起動して作り方を出す**:起動のときの注意(Warn)と、ブラウザのログインの画面に
   「管理者がいません。サーバーの PC で `aibow-server user add <名前>` と `aibow-server user admin <名前>` を打ってください」を出す。
   最初の管理者をコマンドで決める決まり(0018 の決定事項 6)はそのまま。既定の admin は作らない
3. **ログイン必須のときは、127.0.0.1 からの OpenAI 互換の口(Cline など)にも API キーが要る**(今の `KeysRequired` のまま。ブラウザだけ守っても、同じ会話を口から読めては意味が無いため)
4. **ログインなしで使っていた `local` の会話は、起動のときに知らせる**:ログインが要る形で、`local` に会話があってパスワードが無ければ、
   「`aibow-server user passwd local` でパスワードを作ってログインするか、`login: false` で起動してください」を起動のときに出す。会話は動かさない

## 決定事項(Code が決めたこと)

5. 管理者がいないことは、ログインの様子の口(`GET /aibow/auth/me`)の `setup: true` で画面に伝える(ログインしていない人にも見える。管理者がいるかどうかだけで、名前は出さない)
6. 起動のときの「ログインなしで使えます」の行は、ログインなしを選んだときの注意(Warn)にする(選んだことが分かるように)

## 確かめたこと(2026-10-26)

- 一時フォルダの `server.json`(`login` を書かない)で起動:ログに「管理者がいません。…」の注意と「ブラウザの画面はログインが要ります」・「API キーが要ります」。
  `GET /aibow/auth/me` は `{"login": true, "setup": true}`、キーなしの `/v1/models` は 401。ブラウザ(Chrome)のログインの画面に、管理者の作り方の2つのコマンドが1行ずつ出る
- 動かしたまま `user add alice`・`user admin alice` を打つと、`me` から `setup` が消える
- `-login=false` で起動:「ログインなしで使います(login: false。…)」の注意が出て、`me` は `{"login": false}`
- `local` の会話の知らせ:`TestNoteFirstRun`(パスワードの無い `local` に会話があれば出る・パスワードを作れば出ない)。既定の決め方は `TestResolveLogin`(何も書かない / 環境変数・設定ファイル・引数で外す)

## やらないこと

- 画面から最初の管理者を作る(0018 の決定事項 6 のまま)
- `local` の会話をほかの利用者に移す
