## 目的

今の設定の画面(一覧の下の歯車)は、アプリ全体の設定と「開いている会話の設定」(新しい会話の画面では、これから作る会話の設定)を同じ画面で変えている。
これを分け、会話ごとに設定を変える画面を作る。最後は、会話の中でツールを1つずつ絞る・信頼する(確認しない)ところまで、この画面で決められるようにする。

## 進め方(ユーザーと決めたこと)

- **段階に分けて作る**。まず「設定の画面 → 会話の設定」の受け渡し(新しい会話は既定の写しから始まり、会話ごとに変える)を作って確かめ、そのあと上の画面(設定の画面)から順に足していく
- ツールごとの扱いは、最後は「確認しない」まで会話の設定の画面で選べるようにする。ただし1段目ではやらない

## 決定事項

### 1段目(この段)

1. **会話の一覧の各行に歯車のアイコンを置き、削除(×)の左に並べる**。押すとその会話の設定の画面を開く(ユーザーの指定)
   - 歯車と削除は、マウスを乗せた行・開いている行にだけ出す(今の削除と同じ)
   - 開いていない会話の歯車を押したら、その会話を開いてから設定の画面を出す(設定の変更は開いている会話に対して行うため)
2. **会話の設定の画面**(`ConversationSettingsView.tsx`)は、設定の画面と同じく、チャットの代わりに会話の場所に出す別の画面
   - 中身: その会話の設定(システムプロンプト・compact・temperature・presence penalty・思考)、「この設定を新しい会話の既定にする」、ツール(下の 5)、モデルに渡した文字列(開いている会話のものなので、設定の画面から移す)
   - 閉じるのは、「会話に戻る」・同じ歯車をもう一度・一覧で会話を選ぶ・「+ 新規」・一覧の下の歯車(設定の画面に切り替わる)
3. **設定の画面の「この会話の設定」は「新しい会話の既定」にする**(ユーザーと決めた)。開いている会話に関係なく、新しい会話の既定を直接変える
   - 変えたらすぐ保存する(会話の設定と同じく、少し待ってまとめて送る)
   - 新しい会話の画面で開いていたら、これから作る会話の設定(既定の写し)にも同じ変更を入れる
   - 「この設定を新しい会話の既定にする」は会話の設定の画面に移す(設定の画面では意味が無くなるため)
4. 会話の設定と既定の保存は、Go の今ある口を使う(会話の設定は `UpdateConversationSettings`、既定は `SetDefaultSettings`)
5. **会話の設定の画面に、この会話でのツールの状態を出す**(2026-10-15、ユーザーの指示。グループごとの使う / 使わないは今でも会話で選べるため)
   - グループ(組み込み / MCP のサーバー)のチェックは「この会話で使うか」。入力欄の上の「この会話のツール」と同じ設定(`builtin_off` / `mcp_servers`)で、ここからも変えられる
   - ツールごとの行は**見せるだけ**(チェックは押せない)。使えないツールには理由を添える:「この会話で使わない」(会話の上書き `tool_policies`)・「PC の既定で使わない」(`tools.json`)・「作業フォルダが要る」
   - 確認する / 確認しないは出さない(確認を画面で扱う段で足す)
   - 扱いは Go が決めて返す(`Conversations.ToolStates`。`toolPolicy` と同じ `policyOf` を使う)。画面で同じ判断を書き直さない(扱いを決める場所を1つにする、0006 の方針)
   - MCP のサーバーのツールは、起動していなくても、最後に起動したときに覚えた一覧(`tools.json` の `known`)から出す。一覧が無ければ「(ツールの一覧はまだありません)」
   - 使っているグループは開き、使っていないグループは畳んで ▶ で開ける(設定の画面の「ツール」と同じ)
